2. GCN Ne Yapar?

GCN, graph üzerindeki node'ların komşularından bilgi toplayarak temsil öğrenmesini sağlayan bir neural network'tür. Bizim problemimizde modelin amacı, bir sgRNA ile bir target arasındaki candidate edge için pozitif off-target aktivitesi olup olmadığını tahmin etmektir. 

sgRNA node özellikleri
+ target node özellikleri
+ candidate edge feature'ları
→ GCN message passing
→ edge classifier
→ bu sgRNA-target çifti pozitif mi negatif mi?
Message passing Node'ların graph komşularından bilgi almasıdır. Örneğin bir sgRNA, bağlı olduğu target'lar ve varsa similarity relation'ları üzerinden temsilini günceller.
Edge classifier Öğrenilen sgRNA ve target temsillerini, candidate edge feature'larıyla birleştirip o edge için label tahmini yapan son katmandır.
Weighted BCE Binary classification loss'udur. Sprint 4'te class imbalance'a karşı sabit başlangıç loss'u olarak kullanıldı; loss sweep yapılmadı.
Validation-selected threshold Pozitif/negatif karar eşiği testten değil validation setinden seçildi. Test sadece final raporlama içindi.
Teknik ama önemli detay: Sprint 4 GCN'inde candidate edge feature'ları GCNConv message passing içine attention gibi girmez; final edge classifier tarafında kullanılır. Edge-aware attention daha sonraki GAT/GATv2 sprintlerinin konusudur.

3. Sabit Deney Kontratı

Sprint 4'te graph modeli eğitildiği için leakage riski daha da kritik hale geldi. Bu nedenle Sprint 2 ve Sprint 3'te kilitlenen label, split, measured-only ve strict-inductive kuralları aynen korundu.

Kural Sprint 4'te uygulama
Label Scheme A: cleavage_freq > 1e-5.
Split sprint2_main_seed42 guide-level split; aynı guide train ve testte birlikte yok.
Evaluation universe Main train/validation/test measured-only; experiment_id=18 dışarıda.
Graph visibility strict_inductive_primary; held-out auxiliary relation'lar training referanslarına bağlandı.
Checkpoint Validation AUPRC ile seçildi; test performansı model seçimine girmedi.
Threshold Validation max-F1 ile seçildi; test threshold tuning yapılmadı.
Primary metric AUPRC. Test positive prevalence 0.900705 ile birlikte yorumlandı.
Neden AUPRC? Test setinde pozitif oranı çok yüksek olduğu için F1 veya accuracy tek başına yanıltıcı olabilir. AUPRC, score ranking kalitesini ve pozitif sınıf ayırımını daha uygun şekilde gösterir.

4. Ne İnşa Ettik?

Sprint 4 sadece model sonucu üretmedi; aynı zamanda Sprint 3 graph artifact'larını güvenli şekilde model-facing PyTorch Geometric yapısına taşıyan altyapıyı da kurdu.

Model ve loader hattı

  • Sprint 3 typed graph tabloları PyTorch Geometric HeteroData view'larına materialize edildi.
  • Loader, graph manifest count, label scheme, split ID, visibility policy ve feature placement drift'lerini fail-fast kontrol etti.
  • Raw ID, coordinate ve reporting metadata predictive tensor olarak modele sokulmadı.
  • GCN modeli 2 katmanlı, hidden dimension 128, dropout 0.2 olacak şekilde konfigüre edildi.
  • Training için weighted BCE, AdamW, gradient clipping, ReduceLROnPlateau scheduler ve validation AUPRC early stopping kullanıldı.
  • Full eğitimler Colab GPU üzerinde repository komutlarıyla çalıştırıldı; Colab scientific logic'in kendisi olmadı, sadece runner oldu.

Raporlama çıktıları

Her graph için result CSV, Markdown report, diagnostic tablolar, training curve, PR/ROC curve, score distribution, confusion matrix, decile lift, per-genome metric ve graph-view sanity figure üretildi.

5. Alt Deneyler: Graph A, Graph B, Graph C

Sprint 4'te üç graph şeması aynı GCN ailesiyle değerlendirildi. Graph A ve Graph C ana karşılaştırmalardı; Graph B ise yalnızca bounded secondary control olarak çalıştırıldı.

Graph A

Minimal physical-target GCN

sgRNA node'ları fiziksel target site node'larına bağlandı. Target node featureless kaldı; sequence/mismatch feature'ları candidate edge üzerinden verildi.

Graph B

Guide-similarity control

Graph A'nın aynısı korundu, ek olarak guide'lar arasına label-free sequence_similar_to edge'leri eklendi. Amaç sadece topology katkısını test etmekti.

Graph C

Context-observation GCN

Target node fiziksel koordinat yerine target_observation oldu. Context node feature olarak verildi, benzer context observation'ları context_similar_to relation'larıyla bağlandı.

Graph A: minimal baseline

sgRNA_i  --candidate_pair-->  physical_target_site_j

feature_set = S1_pair + F1
target_node_representation = zero_type_feature

Graph A'nın görevi ilk güvenilir GCN baseline'ı olmaktı. Fiziksel target node'lar featureless tutuldu; böylece model target coordinate veya row ID gibi gizli shortcut bilgileri kullanmadı.

Graph B: topology-only kontrol

sgRNA_i --sequence_similar_to--> sgRNA_j
sgRNA_i --candidate_pair-------> physical_target_site_j

Graph B, Graph A'nın target temsilini ve candidate feature'larını değiştirmedi. Tek fark guide similarity edge'leriydi. Bu yüzden Graph B, Graph C'deki daha büyük değişimi yorumlamak için temiz bir kontrol noktası sağladı.

Graph C: context-aware comparison

sgRNA_i --candidate_pair--> target_observation_k
target_observation_k --context_similar_to--> target_observation_m

target_node_representation = target_observation_context_encoder

Graph C'de context, target observation node'larına taşındı. Bu tasarım, aynı fiziksel target'ın farklı satırlarda farklı context ile görülebilmesi problemine karşı geliştirilmişti. Ancak Graph C, topology-only değildir; hem relation yapısı hem de target node anlamı değişir.

7. Literatürle Eşleşmesi

Sprint 4'ün literatürle ilişkisi doğrudan "aynı paper'ı reproduce ettik" şeklinde değil, "literatürdeki GCN/link-prediction fikrini daha sıkı guide-level evaluation altında uyguladık" şeklinde kurulmalıdır.

Literatür Sprint 4'e katkısı Bizim farkımız
Kipf & Welling 2017 GCN'in temel message-passing fikrini sağlar: node'lar komşu bilgisinden temsil öğrenir. Biz bunu edge classification/link prediction için sgRNA-target graph'ına uyguladık.
Vinodkumar et al. 2021 CRISPR off-target prediction için GCN/link-prediction yaklaşımını motive eder. Random-edge evaluation yerine guide-level, measured-only, leakage-controlled split kullandık.
Mak et al. 2022 Epigenetik ve nucleosome context feature'larının off-target aktivitesiyle ilişkili olduğunu gösterir. Mak'in CA regression setup'ını reproduce etmedik; Scheme A binary classification yaptık.
PR/imbalance literatürü AUPRC'nin dengesiz sınıf dağılımında primary metric olarak raporlanmasını destekler. F1/MCC gibi threshold-dependent metrikleri secondary yorum olarak tuttuk.
Sunum cümlesi: Sprint 4, literatürdeki CRISPR-GCN fikrini doğrudan kopyalamak yerine, Mak/crisprSQL dataset'i üzerinde guide-level, leakage-controlled ve güçlü tabular baseline'a karşı test eden ilk graph-model basamağımızdır.

8. Yorum Sınırları ve Sonraki Sprintlere Devir

Sprint 4 sonuçları önemli ama sınırlıdır. Burada yapılan şey ilk GCN baseline'ı kurmaktır; attention, kapsamlı feature ablation veya imbalance-method çalışması bu sprintin konusu değildir.

Bu sprintte yapmadıklarımız

  • GAT veya GATv2 denemedik; attention karşılaştırması daha sonraki sprintlere bırakıldı.
  • Epigenetik feature family ablation yapmadık; bu Sprint 5'in konusuydu.
  • Focal loss, sampling veya systematic imbalance loss sweep yapmadık; bu Sprint 6'nın konusuydu.
  • Graph C'nin context topology mi, direct node feature mı etkili sorusunu ayrıştırmadık; bu daha sonra Sprint 7D/7E'de test edildi.
  • Test sonucuna göre model veya feature seçmedik.

Sprint 4'ün sonraki sprintlere bıraktığı sorular

  • GCN edge feature'ları yeterince iyi kullanıyor mu, yoksa feature family ablation gerekiyor mu?
  • Binding energy veya epigenetik feature eklemek Graph A GCN'i güçlendirir mi?
  • Threshold collapse ve rare-negative tanıma problemi loss/sampling ile iyileşir mi?
  • GAT/GATv2 attention, candidate edge feature'larını message passing içine daha etkili sokabilir mi?
  • Graph C'de asıl katkı context edge'lerinden mi, direct target_observation feature'larından mı geliyor?
En kritik yorum sınırı: Sprint 4'te hiçbir GCN modeli primary AUPRC'de XGBoost F4'ü geçmedi. Bu yüzden tez anlatısında GNN'i "daha iyi tahmin modeli" diye değil, "graph/context temsillerini sistematik olarak test eden deney hattı" diye konumlandırmak gerekir.

9. Final Özet

Sprint 4, projenin ilk gerçek GCN modelleme sprintidir. Sprint 3'te hazırlanan leakage-controlled Graph A/B/C artifact'ları PyTorch Geometric HeteroData yapısına materialize edilmiş, ardından GCN edge-classification modeli ile aynı guide-level, measured-only ve strict-inductive kontrat altında eğitilmiştir. Graph A minimal physical-target baseline olarak, Graph B guide-similarity topology control olarak, Graph C ise context-observation comparison olarak çalıştırılmıştır. Sonuçta Graph A, Graph B ve Graph C geçerli GCN sonuçları üretmiş olsa da hiçbirisi primary metric olan test AUPRC'de xgboost_unweighted / F4 baseline'ını geçememiştir. Graph C, MCC bakımından Graph A'dan daha iyi görünmüş fakat bu secondary ve threshold-dependent bir metrik olduğu için ana başarı iddiası yapılmamıştır. Bu sprintin esas katkısı, GNN hattının çalıştığını, graph schema karşılaştırmasının adil biçimde yapılabildiğini ve sonraki feature ablation, imbalance learning ve attention sprintleri için sağlam, sızıntısız bir deney zemini kurduğunu göstermesidir.
