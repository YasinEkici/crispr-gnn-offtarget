# Survey on deep learning with class imbalance

## Citation

Johnson, J. M., & Khoshgoftaar, T. M. (2019). Survey on deep learning with class imbalance. *Journal of Big Data*, 6, 27. https://doi.org/10.1186/s40537-019-0192-5

## Core Idea

This survey reviews deep learning approaches for class imbalance, including sampling, cost-sensitive learning, metrics, and architecture/training considerations.

## Project Relevance

It is a broad background reference for Sprint 6's loss/sampling comparison. It also supports the distinction between data-level sampling methods and loss/threshold-level controls.

## Project Difference

The project's measured-only headline is positive-heavy while much CRISPR off-target literature is negative-heavy. General imbalance advice must therefore be applied under the actual local class geometry, not by assuming the same minority class as genome-wide off-target screens.

## Claim Boundary

Use this survey for taxonomy and general framing. The Sprint 6 empirical result remains project-specific: weighted BCE was the best predeclared objective under fixed Graph A + S5F2_energy.
