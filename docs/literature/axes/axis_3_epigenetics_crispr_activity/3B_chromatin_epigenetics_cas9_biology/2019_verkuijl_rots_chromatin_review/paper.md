# The Influence of Eukaryotic Chromatin State on CRISPR-Cas9 Editing Efficiencies

## Citation

Verkuijl, S. A. N., & Rots, M. G. (2019). The influence of eukaryotic chromatin state on CRISPR-Cas9 editing efficiencies. *Current Opinion in Biotechnology*, 55, 68-73. https://doi.org/10.1016/j.copbio.2018.07.005

## Core Idea

This review summarizes evidence that eukaryotic chromatin state affects CRISPR-Cas9 editing efficiency. It is a biology-oriented reference for why accessibility, nucleosome occupancy, and epigenetic state are reasonable modeling context.

## Project Relevance

The review helps frame Sprint 7E/7F's finding that target-observation and experimental epigenetic context features are important in the local Graph C GATv2 experiments.

## Project Difference

The review is not a machine-learning benchmark and does not validate this project's particular feature engineering choices. It supports biological plausibility, not causal proof.

## Claim Boundary

Use to motivate chromatin-context features and to keep interpretation cautious: strong model signal is not the same as biological causality.
