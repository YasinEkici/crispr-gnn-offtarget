# DIG-seq: a genome-wide CRISPR off-target profiling method using chromatin DNA

## Citation

Kim, D., & Kim, J.-S. (2018). DIG-seq: a genome-wide CRISPR off-target profiling method using chromatin DNA. *Genome Research*, 28(12), 1894-1900. https://doi.org/10.1101/gr.236620.118

## Core Idea

DIG-seq profiles genome-wide CRISPR off-target sites using chromatin DNA, providing an assay perspective that explicitly accounts for chromatin context.

## Project Relevance

This paper helps motivate why chromatin-aware features are relevant for off-target prediction. It supports the broader biological framing behind Mak/crisprSQL epigenetic descriptors and Graph C target-observation context.

## Claim Boundary

Use this as assay/biology context. It is not a direct evaluation benchmark for the project's measured-only classification split.
