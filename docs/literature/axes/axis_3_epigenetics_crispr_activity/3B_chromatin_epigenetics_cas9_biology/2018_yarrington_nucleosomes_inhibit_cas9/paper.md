# Nucleosomes inhibit target cleavage by CRISPR-Cas9 in vivo

## Citation

Yarrington, R. M., Verma, S., Schwartz, S., Trautman, J. K., & Carroll, D. (2018). Nucleosomes inhibit target cleavage by CRISPR-Cas9 in vivo. *PNAS*, 115(38), 9351-9358. https://doi.org/10.1073/pnas.1810062115

## Core Idea

The paper provides in vivo evidence that nucleosome-bound targets are cut less efficiently by CRISPR-Cas9 than nucleosome-free targets.

## Project Relevance

This supports the biological motivation for nucleosome-related target-context features in the Mak/crisprSQL lineage and in the project's Graph C target-observation node features.

## Claim Boundary

Use this paper as mechanistic motivation for considering nucleosome context. It does not make the project's learned context features causal evidence by itself.
