# Literature Index

Literature notes are organized by research axis under `docs/literature/axes/`.

## Axes

- `axis_1_crispr_prediction_models/` - GNN-based and sequence-based CRISPR off-target / on-target prediction models.
- `axis_2_imbalance_cost_sensitive_learning/` - class imbalance and cost-sensitive learning.
- `axis_3_epigenetics_crispr_activity/` - epigenetic features, chromatin context, and CRISPR-Cas9 activity.

Each paper should live under one primary subsection with:

```text
<paper_id>/
├── original.pdf
├── metadata.yaml
├── paper.md
└── assets/
    ├── figures/
    └── pictures/
```

Use `paper_registry.yaml` as the central index when papers are added.
